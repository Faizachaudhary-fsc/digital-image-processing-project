Digital Image Processing – Foreground Segmentation & Background Replacement

Successfully completed a semester project on Foreground Segmentation and Background Replacement using Python.

This project implements classical Digital Image Processing techniques for preprocessing, foreground segmentation, mask refinement, and pixel-level background replacement. A simple GUI was developed using tkinter to allow dynamic image selection at runtime.

The system extracts the foreground from the first image, removes its background, and replaces it with a new background image selected by the user.

Features
- Foreground extraction
- Background removal
- Background replacement
- User-friendly GUI
- Dynamic image upload

Tools & Technologies
- Python
- OpenCV
- tkinter
- GrabCut Algorithm
- Image Segmentation
- Morphological Operations

Learning Outcomes
This project helped me gain practical insight into real-world image processing systems and understand their limitations when handling complex images.

Keywords
Digital Image Processing, Python, OpenCV, tkinter, Computer Vision, GrabCut, Image Segmentation
